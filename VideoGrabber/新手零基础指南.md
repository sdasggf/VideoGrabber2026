# 给魏的零基础上手指南（完全不懂也能照做）

> 你不用懂任何编程。下面每一步都告诉你"点哪里、会看到什么、填什么"。
> 照着做就行，卡住了随时把屏幕上的字或截图发我，我接着帮你。

---

## 一、你需要准备的东西
- 一台能上网的电脑（Windows / Mac 都行）
- 你的安卓手机 + 一根数据线（最后装 App 用）
- 一个能收邮件的邮箱（注册账号用）

## 二、先弄明白一件事（不用懂原理）
我给你的不是"装好就能用的安装包"，而是一套"配方（工程代码）"。
原因：你的电脑里没有把配方变成安装包的工具，所以我准备了一个"云厨房"——**GitHub 自动构建**。
你把配方上传过去，云端免费帮你做好安装包（.apk），你下载回来装手机即可。
你全程**不用装任何编程软件**。

---

## 三、第 1 步：注册一个 GitHub 账号
1. 打开浏览器，在地址栏输入 `https://github.com` 并回车。
2. 点右上角的绿色按钮 **Sign up**（意思是"注册"）。
3. 按页面填写：
   - **Username（用户名）**：随便取，英文或数字，例如 `wei2026`（后面能改显示名，但这个 ID 一旦定下不好改，无伤大雅）。
   - **Email（邮箱）**：填你能收邮件的那个。
   - **Password（密码）**：自己记好。
4. 做一下人机验证（拼图或打勾），然后点 **Create account**（创建账号）。
5. 去你的邮箱收一封验证邮件，点里面的链接完成验证。

## 四、第 2 步：新建一个"仓库"（就是放配方的网上文件夹）
1. 登录后，点页面右上角你的头像**左边**那个 **+** 号，选 **New repository**（新建仓库）。
2. 填写：
   - **Repository name（仓库名）**：填 `VideoGrabber`（随意，记住它就行）。
   - 下面 **Public / Private** 选 **Public**（公开，免费；选 Private 也行但有些功能要付费，先选 Public）。
   - 勾选 **Add a README file**（打勾，让仓库不为空）。
3. 点绿色 **Create repository**（创建仓库）。

## 五、第 3 步：把工程文件夹上传进去
1. 建好后会进入仓库页面。点页面上的 **Add file** 按钮 → 选 **Upload files**（上传文件）。
2. 进入"拖文件到这里"的页面。
3. 在你自己的电脑上，找到之前下载并解压出来的 **VideoGrabber** 文件夹。
4. 把这个文件夹里的**所有内容**拖到网页的虚线框里（也可以直接把整个 VideoGrabber 文件夹拖进去，网页会保留结构）。
   - 提示：文件不多，几秒到一分钟传完。
5. 拉到页面最底部，在 **Commit changes** 下面的小框里随便写点字（如 `init`），然后点绿色 **Commit changes**（提交）。

## 六、第 4 步：等云端帮你做安装包
1. 上传完后，点仓库顶部的 **Actions** 标签（在 Code / Issues / Pull requests 那一行里）。
2. 你会看到一条叫 **Build Debug APK** 的记录，左边先是黄色转圈。
3. 等它变成**绿色对勾 ✓**（大概 3–8 分钟，期间可以去喝口水）。
4. 如果变成**红色叉 ✗**：别慌，把那个页面截图发我，我帮你看哪里出问题。

## 七、第 5 步：下载安装包（.apk）
1. 点进那条绿色 ✓ 的记录。
2. 页面往下拉，找到 **Artifacts**（构件）区域，里面有一个 `videograbber-debug-apk`，点它下载（是个 zip 压缩包）。
3. 解压这个 zip，里面得到 `app-debug.apk` —— 这就是能装到手机的安装包。

## 八、第 6 步：装到手机
1. 把 `app-debug.apk` 通过数据线 / 微信文件传输 / 网盘，弄到你的安卓手机上。
2. 在手机上点这个文件，系统可能弹出"是否允许安装未知来源应用"→ 点**允许**（或按提示去设置里打开开关）。
3. 完成安装。

## 九、第 7 步：先验证主功能（这一条不依赖高级功能）
1. 打开刚装好的 App，底部选「浏览器」。
2. 页面里默认就有一个测试视频，点底部的「下载：xxx」按钮。
3. 看进度条走到 100%，提示完成。
4. 打开手机相册 → 找 `Movies/VideoGrabber` 文件夹，里面就是下载好的视频。

> 这一步（浏览器里下载视频 → 转成 mp4 → 存相册）是最核心、最稳的功能，不依赖任何高级抓取，先确认它能跑通。
